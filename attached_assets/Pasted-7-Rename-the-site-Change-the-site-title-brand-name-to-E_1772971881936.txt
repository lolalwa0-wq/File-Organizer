9. Interactive Negativity-Cleansing Card Animations ⚡
This is the most important visual effect. Each service card should have a "negativity layer" — a dark, smoky overlay on the card that gets cleansed when the user interacts.

How it works:
Each card starts with a subtle dark smoky/foggy overlay on top (like dark negative energy clinging to it). When the user hovers, the negativity gets cleansed differently depending on the card:

🕯️ WAX card — Gentle, slow cleansing:
CSS

/* Dark negativity overlay on the card */
.wax-card .negativity-layer {
  position: absolute;
  inset: 0;
  background: radial-gradient(
    ellipse at center,
    rgba(20, 0, 30, 0.6) 0%,
    rgba(40, 10, 50, 0.4) 40%,
    rgba(10, 5, 15, 0.3) 100%
  );
  transition: opacity 2s ease-in-out; /* SLOW and GENTLE — 2 seconds */
  pointer-events: none;
  border-radius: inherit;
}

.wax-card:hover .negativity-layer {
  opacity: 0; /* negativity gently fades away */
}

/* Card underneath becomes clean and glows like a diamond */
.wax-card {
  transition: all 2s ease-in-out;
}

.wax-card:hover {
  box-shadow: 
    0 0 20px rgba(201, 162, 39, 0.2),
    0 0 60px rgba(201, 162, 39, 0.1),
    inset 0 0 30px rgba(255, 255, 255, 0.05);
  border-color: rgba(201, 162, 39, 0.4);
  /* Clean like a diamond — bright and pure */
}
Also: when hovering on the CTA button ("Записаться") inside the wax card, add an additional gentle golden pulse that radiates outward, like the last bit of negativity softly leaving.

.lead-card .negativity-layer {
